The manual improv-poke is a **MANDATORY BRACKET** — ALWAYS, before AND/OR after the corpus, never skipped, never limited to corpus classes. The manual poke SURPASSES auto-orchestrated skills.

Run it apparatus-OFF **first** (subtractive, not additive): follow the one weird thing, add one more input, with ZERO gate/corpus/schema/workflow allowed to run. The apparatus (nuke/intake/wide/darkside/workflow fan-out) fires only AFTER — to package findings + not-miss-anything (its real role: completeness/packaging, NOT discovery).

**Why:** a workflow MAPS the surface but does not READ it. Only once the thread is exhausted by hand do you let the apparatus run to package. If a skill returns "null/fortress", the poke-the-mapped-claim pass is mandatory before believing it.
