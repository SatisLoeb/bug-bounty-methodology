The manual, improvised **cold-poke** is a MANDATORY bracket — always, before AND/OR after the corpus/skills, never skipped, never limited to the corpus's classes. It SURPASSES auto-orchestrated skills.

**Why:** the corpus/skill-set is a bounded expectation-set = the story of whoever extracted it, where THEY believed bugs live (Second Maxim applied to tooling, not just code). The bug is always an indirection OUTSIDE where you reached clean understanding — the surface no class names. Live proof: a cold-poke found `admin-api.injective.network` (a whole privileged, live, DB-connected backend) by following ONE JWT claim (`aud:injective-admin-api`) that an 11-agent workflow had MAPPED without READING — the workflow rendered "fortress-null on the signing seam" while a whole admin host was one claim away. Same for the `granterAddress` ATO, found by poking the auth flow by hand for two days. A skill/workflow MAPS; it does not READ the weird thing.

**How to apply:**
- Discovery pass is SUBTRACTIVE, not additive: apparatus OFF first — no gate, no corpus, no schema, no workflow allowed to run. Follow the ONE weird thing, one more input at a time, by hand. The apparatus fires only AFTER, to package + miss-nothing (its real role = completeness backstop WITHIN known classes).
- ORDER IS EVERYTHING: poke FIRST (discovery — finds the bug the corpus has no class for), apparatus AFTER (packaging — catches the classes the poke missed).
- The tell you skipped it: you rendered a "fortress-null / RE-SOURCE" from skills/workflows without a by-hand poke of the thing you MAPPED but never READ (dismissed dirs, an "OOS admin" contract, a config address, a claim/field you noted but didn't follow). RE-SOURCE-after-skills IS "more machinery"; the poke is the discipline.
- NEVER respond to a miss with more machinery. Deletion or discipline, never a new process.

Explicit, assumed tension with [[feedback-replicate-protocol-check-before-claiming-extraction]] and the corpus-coverage-gate rule: BOTH are true. The gate/corpus catches the classes the poke misses (packaging); the poke finds the bug for which the corpus has no class (discovery). Applied on Boros [[project-boros-onchain-core-3vein-null]]: the 3-vein null was skill-rendered — the un-poked mapped surfaces (admin/, offchain-helpers/, generated/, PendleMulticallOwner arbitrary-call, deployed vanity addresses) are exactly where the poke must run before any RE-SOURCE.
