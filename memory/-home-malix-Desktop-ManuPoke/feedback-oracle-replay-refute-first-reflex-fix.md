The oracle/replay arsenal is a machine for REFUTING plausible findings, zero landed wins ([[reference-arsenal-vs-immunefi-top10-coverage-map]]). A 4-agent workflow (2 adversarial researchers vs real 2023-2026 landed bounties + 2 corpus reflex-locators) returned **PARTIALLY_SUPPORTED** with a sharper root cause than "wrong sub-class."

**Why:** The instrument fires ONLY its refutation kernel — manipulation-COST for oracle, on-chain-NONCE-presence for replay — and it's run against SATURATED audited targets (Chainlink/TWAP/deep-liq oracle cores; audited nonce-guarded SC cores). On those targets refutation is the CORRECT verdict, so it produces true-negatives all day. TWO compounding errors: (1) **reflex-order** — the manipulation-cost gate over-scopes to "ANY lagging-oracle" and the nonce check treats presence as strength (First-Maxim violation), so a cost-free integration bug gets routed through a P&L / conceded the moment binding moves off-chain; (2) **target-selection** — every corpus deployment (Metric, Jupiter, OKX, Stackup, Peggy, Across) aimed the lens at the pre-swept surface (same failure firmaudit T6d already named across 5 fortresses). NOT class-death: single-pool manipulation still lands $2.4M (Yellow), $1.65M (Allbridge); nonce-present still lands via edge-math (the diamond in the wall).

**How to apply — 3 legs:**
1. **Invert reflex order (cost-free / off-chain FIRST).** Oracle: run a deterministic FREE-READ checklist BEFORE any manipulation/window gate — updatedAt-vs-heartbeat, decimals/exponent match, answer>0 & not at min/maxAnswer clamp, L2 sequencerUptimeFeed, price-getter not read-only-reenterable, consumer REVERTS (not swallows) on a bad tuple. Each is one cast_call, no fork, no P&L. Manipulation-cost applies ONLY to findings that REQUIRE pushing a price. Replay: when the on-chain sink consumes NO nonce, the off-chain signing flow is the PRIMARY vein (GO signal), never OOS — force a capture-and-replay artifact before any NULL; a README "signs per-tx / blockhash-bound" claim does NOT close it. And enumerate what the digest SHOULD bind but doesn't (EIP-712 field-omission = highest-EV replay sub-class).
2. **Re-aim the SAME instrument at UNSATURATED targets.** Manipulation → single-pool/low-liquidity oracles (not TWAP/deep-liq). Nonce/domain → fresh off-chain signers + un-competed multi-chain deployments. Stop bringing these lenses to audited cores where the guard exists by construction.
3. **Build the 2 missing EXECUTED artifacts.** (a) Oracle CONSUMER-side free-read harness (mock feed → each pathological tuple → assert the borrow/mint/liquidate entrypoint reverts; current DepOracleFuzz tests the wrapper's own isStale, the WRONG layer). (b) TWO-LIVE-FORK cross-chain replay harness (same contract on 2 forks / shared DOMAIN_SEPARATOR; capture sig on fork A, replay on fork B; assert execute-vs-reject) — converts every "domains can't collide" reasoned-NULL into an artifact.

**Calibration (be honest):** modal severity of the cost-free classes is **MEDIUM, money is in VOLUME** (sequencer-uptime is the single most-repeated Sherlock/C4 finding; staleness/conf mostly Medium). HIGH/Crit only when the defect sits directly on a mint/transfer/liquidation/quorum. So the true reframe is "a steady stream of Medium + occasional High left in the wall," not "a crown jewel missed." Corrects the over-scope in [[feedback-model-manipulation-cost-before-crediting-twap-finding]].
